# From Software Applications to Hardware

## Introduction

Software applications are eventually converted into machine instructions that are executed by hardware.

---

## Simplified Flow

```text

     ↓

     ↓
Compiler
     ↓
Assembly / Machine Code
     ↓
Instruction Set Architecture
     ↓
Processor
     ↓
Digital Logic
     ↓
RTL
     ↓
Logic Gates
     ↓
Standard Cells
     ↓
Physical Layout
