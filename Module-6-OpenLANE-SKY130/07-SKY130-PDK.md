# SKY130 PDK

## What is a PDK?

PDK stands for **Process Design Kit**.

A PDK provides the technology-specific information required for designing integrated circuits for a particular semiconductor process.

---

# SKY130

SKY130 is an open-source 130 nm semiconductor process design kit.

---

## PDK Contents

A PDK can contain:

- Technology files
- Standard-cell libraries
- LEF files
- Liberty files
- SPICE models
- Design rules
- Extraction information
- Physical verification information
- Cell layouts
