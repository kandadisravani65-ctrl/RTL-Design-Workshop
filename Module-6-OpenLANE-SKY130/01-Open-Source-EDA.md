# Open-Source EDA

## What is EDA?

EDA stands for **Electronic Design Automation**.

EDA consists of software tools used to design, simulate, synthesize, verify and implement electronic circuits.

---

## What is Open-Source EDA?

Open-source EDA refers to EDA tools that are openly available and can be used to study and implement electronic designs.

---

## Important Open-Source EDA Tools

| Tool | Purpose |
|------|---------|
| Yosys | RTL synthesis |
| OpenROAD | Physical design |
| Magic | Layout and verification |
| OpenLANE | ASIC implementation |
| Icarus Verilog | Verilog simulation |
| GTKWave | Waveform analysis |

---

## Advantages

- Free and accessible
- Useful for education
- Useful for research
- Open and customizable
- Helps understand ASIC design internally
- Supports reproducible design flows

---

## Key Learning

Open-source EDA allows designers and students to explore the complete digital ASIC design process using freely available tools.
