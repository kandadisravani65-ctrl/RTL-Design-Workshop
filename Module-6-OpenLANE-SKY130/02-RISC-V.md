# RISC-V

## What is RISC-V?

RISC-V is an open and extensible **Instruction Set Architecture (ISA)**.

An ISA defines the instructions that a processor can understand and execute.

---

## Important Features

- Open ISA
- Modular architecture
- Extensible instruction set
- Suitable for processor design
- Suitable for embedded systems
- Suitable for SoC development
- Useful for academic and industrial research
