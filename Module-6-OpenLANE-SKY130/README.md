# Module 1 — Inception of Open-Source EDA, OpenLANE and SKY130 PDK

## 📌 Introduction

This module introduces the fundamentals of open-source digital ASIC design.

The module focuses on understanding open-source EDA, RISC-V, SoC design, the transition from software applications to hardware, the RTL-to-GDSII flow, OpenLANE, SKY130 PDK, design preparation and synthesis.

---

# 🎯 Objectives

The main objectives of this module are:

- Understand the concept of Electronic Design Automation.
- Understand open-source EDA tools.
- Understand RISC-V architecture.
- Understand System-on-Chip design.
- Understand how software is converted into hardware operations.
- Understand the RTL-to-GDSII design flow.
- Understand OpenLANE and its role in ASIC design.
- Understand the SKY130 Process Design Kit.
- Understand the OpenLANE directory structure.
- Perform design preparation.
- Perform RTL synthesis.
- Analyze synthesis results.

---

# 📚 Topics Covered

### 1. Open-Source EDA
Introduction to Electronic Design Automation and open-source EDA tools.

### 2. RISC-V
Introduction to the open RISC-V instruction set architecture.

### 3. Software to Hardware
Understanding how software applications are eventually executed by hardware.

### 4. SoC and OpenLANE
Understanding System-on-Chip design and the role of OpenLANE.

### 5. RTL-to-GDSII Flow
Understanding the complete digital ASIC implementation flow.

### 6. OpenLANE
Introduction to the open-source ASIC implementation flow.

### 7. SKY130 PDK
Understanding the open-source 130 nm Process Design Kit.

### 8. OpenLANE Directory Structure
Understanding important directories and generated files.

### 9. Design Preparation
Preparing a design for the OpenLANE flow.

### 10. Synthesis
Converting RTL into a gate-level netlist.

### 11. Synthesis Results
Understanding area, cell count, timing and other synthesis parameters.
