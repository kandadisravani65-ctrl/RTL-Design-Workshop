# Pre-Placed Cells

## Definition

Pre-placed cells or blocks are components whose physical locations are decided before standard-cell placement.

---

# Examples

- Memory blocks
- Large macros
- Analog blocks
- IP blocks
- Interface blocks

---

# Why Pre-Placement?

Pre-placement helps:

- Reserve space for large blocks
- Control connectivity
- Reduce routing problems
- Improve floorplan organization

---

# Important Factors

Pre-placed blocks should consider:

- Connectivity
- Power
- Clock
- Routing
- Blockages
- Timing

---

## Key Learning

Large or critical blocks are generally positioned before automatic standard-cell placement.
