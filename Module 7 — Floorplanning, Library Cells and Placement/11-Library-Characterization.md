# Library Characterization

## Introduction

Standard cells must be characterized to understand their timing, power and electrical behavior.

---

# Important Parameters

- Propagation delay
- Transition time
- Input capacitance
- Output capacitance
- Setup time
- Hold time
- Power consumption

---

# Timing Characterization

Characterization determines how a standard cell behaves under different input and output conditions.

---

# Why Characterization?

The characterized information is used by:

- Synthesis tools
- Timing analysis tools
- Physical design tools

---

## Key Learning

Library characterization provides the timing and electrical information required for accurate digital ASIC implementation.
