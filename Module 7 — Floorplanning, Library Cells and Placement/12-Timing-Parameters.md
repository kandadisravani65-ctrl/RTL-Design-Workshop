# Timing Characterization Parameters

## Propagation Delay

Propagation delay is the time taken for a change at the input of a cell to produce a corresponding change at its output.

---

# Types of Delay

### Cell Rise Delay

Delay associated with an output transition from low to high.

### Cell Fall Delay

Delay associated with an output transition from high to low.

---

# Transition Time

Transition time represents the time required for a signal to move between specified voltage levels.

---

# Factors Affecting Delay

Propagation delay can depend on:

- Input transition
- Output capacitance
- Cell size
- Load
- Input slew

---

# Timing Thresholds

Defined voltage thresholds are used to measure:

- Input transition time
- Output transition time
- Propagation delay

---

## Key Learning

Timing characterization provides the information needed to predict how quickly standard cells respond to input changes.
