# Module 0 — Getting Started

## Overview

This module focuses on setting up and understanding the development environment required for RTL and VLSI design.

## Topics Covered

### 1. Cloud Lab Setup

- Introduction to the cloud-based laboratory environment
- Accessing the required development environment
- Understanding the VLSI lab workflow
- Working with the Linux terminal

### 2. Local Lab Setup

- Setting up the VLSI development environment locally
- Installing and configuring the required tools
- Preparing the environment for Verilog simulation and synthesis

### 3. Linux Environment

- Basic Linux terminal commands
- File and directory management
- Navigating the development environment
- Running EDA tools through the terminal

### 4. EDA Tool Environment

The environment was prepared for working with:

- Verilog HDL
- Icarus Verilog
- GTKWave
- Yosys
- SKY130 technology

## Learning Outcome

This module provided the foundation required to work with RTL design and open-source VLSI tools in a Linux-based environment.
