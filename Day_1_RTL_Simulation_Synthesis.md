# Day 1 – RTL Design, Simulation & Synthesis

## Topics Covered

- RTL Design using Verilog
- Design and Testbench
- Icarus Verilog Simulation
- GTKWave Waveform Analysis
- 2:1 Multiplexer
- RTL Synthesis using Yosys
- Gate-Level Representation
- Technology Mapping
- Standard Cell Concepts
- Faster and Slower Cell Flavors

## Tools Used

- Verilog
- Icarus Verilog
- GTKWave
- Yosys
- Linux / Ubuntu
- Git & GitHub

## Key Learning

The RTL design was simulated using testbenches and waveforms were analyzed using GTKWave. The designs were then synthesized using Yosys to understand how RTL is converted into gate-level hardware.
