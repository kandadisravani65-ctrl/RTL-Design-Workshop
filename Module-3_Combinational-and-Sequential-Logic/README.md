# Module 3 — Combinational and Sequential Logic

## Overview

This module focuses on the design, simulation, synthesis and optimization of combinational and sequential digital circuits using Verilog RTL.

## Topics Covered

### 1. Combinational Logic

- Introduction to combinational logic
- Boolean logic
- Logic gates
- Multiplexers
- Decoders
- Encoders
- Arithmetic circuits
- RTL implementation of combinational circuits

### 2. Sequential Logic

- Introduction to sequential logic
- Flip-flops
- Registers
- Clock signals
- Reset signals
- State-dependent behavior
- RTL implementation of sequential circuits

### 3. Lab 06

Practical implementation and verification of combinational/sequential RTL concepts covered in the laboratory exercises.

The work includes:

- RTL design
- Testbench development
- Simulation
- Waveform analysis
- Synthesis

### 4. Lab 07

Practical implementation and verification of sequential logic concepts covered in the laboratory exercises.

The work includes:

- Sequential RTL design
- Clocked behavior
- Testbench development
- Simulation
- Waveform analysis
- Synthesis

### 5. Sequential Logic Optimization

- Understanding RTL implementation
- Identifying unnecessary logic
- Improving RTL coding
- Understanding synthesis optimization
- Comparing different RTL implementations
